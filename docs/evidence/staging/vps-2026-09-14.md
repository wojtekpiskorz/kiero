## Repeatable nonsecret checks

Run from an authenticated issue worktree with the pinned dependencies installed:

```bash
rtk proxy npx --no-install convex env default list --names-only --type prod --project wojtek-piskorz-jr:kiero-dev-core
rtk proxy npx --no-install convex env list --names-only --deployment wojtek-piskorz-jr:kiero-dev-core:staging
rtk proxy gh secret list --repo wojtekpiskorz/kiero --env staging
rtk proxy gh variable list --repo wojtekpiskorz/kiero --env staging
rtk proxy npx --no-install wrangler r2 bucket list --jurisdiction eu
```

The default-variable command requires explicit `--project` in a fresh checkout. The earlier invocation with only `--type prod` refused because no local deployment was selected; it made no changes. `--names-only` is required for every environment-variable inventory.
